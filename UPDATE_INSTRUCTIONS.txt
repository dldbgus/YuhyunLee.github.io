Yuhyun Lee — Minimal Academic Portfolio UPDATE

이 ZIP은 기존 GitHub 저장소를 업데이트하기 위한 것만 담았습니다. 새 저장소를 만들지 마세요.

먼저 바뀐 디자인은 별도로 제공된 미리보기 PNG로 확인하세요.

1. GitHub Desktop에서 현재 저장소를 선택하고 Fetch origin을 누릅니다.
   Pull origin이 보이고 미처리 로컬 변경이 없다면 먼저 Pull origin을 누릅니다.
2. Repository -> Show in Finder를 누르면 기존 GitHub 저장소 폴더가 열립니다.
   폴더 안에 .git 와 index.html이 같이 보이는지 확인하세요.
3. 이 ZIP을 압축 해제해서 나온 내용물을 그 저장소 폴더에 복사합니다.
   - 'styles.css' 같은 동일 이름의 개별 파일은 Replace(대치).
   - 'data', 'source', 'scripts', 'projects' 등 기존 폴더는 Merge(병합).
   - 폴더를 통째로 Replace 하면 기존 콘텐츠가 지워질 수 있으므로 주의하세요.
   - ZIP 폴더 자체를 저장소 안에 넣지 마세요.
   - .git 폴더는 건드리지 마세요.
   - .pages.yml은 Finder에서 Command+Shift+. 으로 숨김 항목을 표시해 복사하세요.
4. GitHub Desktop -> 변경 사항 확인 -> Summary: Refresh academic website design -> Commit to main.
5. Push origin. GitHub 웹사이트 Actions 탭에서 Publish research portfolio의 초록 체크 확인.
6. 이후 https://app.pagescms.org 에서 소개/최근 소식/연구/논문과 이미지 편집이 가능합니다.

중요: 이 파일은 공개 GitHub 저장소를 자동으로 수정하지 않습니다.

업데이트 파일:
- styles.css, project-detail.css: 새 디자인
- source/template.html, scripts/build.py: 새 페이지 구조 및 생성기
- data/site.json, data/news.json: 간결한 연구 소개와 최근 소식
- .pages.yml: Pages CMS에 최근 소식 편집 메뉴 추가
- index.html, projects/*/index.html: 미리 생성된 홈페이지/상세 페이지
- README.md: 사용 안내

프로필 사진이나 연구 이미지는 Pages CMS에서 나중에 업로드하면 됩니다. 아무 사진도 없으면 이미지 없는 텍스트형 학술 페이지로 표시됩니다.
